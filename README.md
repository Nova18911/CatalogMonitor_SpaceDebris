# CatalogMonitor_SpaceDebris

Сущности:
1.Космический объект: каталожный номер, международный идентификатор, тип (действующий спутник / выведенный из эксплуатации аппарат / фрагмент / ступень ракеты), размерная оценка, текущие орбитальные элементы, статус (каталогизирован / утерян / повторно обнаружен), дата последнего наблюдения. Связана с сущностью «Сеанс наблюдения» связью «один-ко-многим» (один космический объект может наблюдаться несколько раз в разных сеансах, сеанс включает в себя наблюдение только за одним объектом).
2.Средство наблюдения: идентификатор средства, тип (радиолокатор / оптический телескоп / лазерный дальномер), зона обзора, чувствительность, режим работы, статус (в строю / на обслуживании / вышло из строя). Связана с сущностью «Сеанс наблюдения» связью «один-ко-многим» (одно средство используется в разных сеансах, несколько сеансов могут использовать одно и то же средство для наблюдения).
3.Сеанс наблюдения: дата и время, средство наблюдения, наблюдаемый объект, полученные данные, результат обработки. Связана с сущностью «Космический объект» связью «один-ко-многим» (один космический объект может наблюдаться несколько раз в разных сеансах, сеанс включает в себя наблюдение только за одним объектом). Связана с сущностью «Средство наблюдения» связью «один-ко-многим» (одно средство используется в разных сеансах, несколько сеансов могут использовать одно и то же средство для наблюдения).
4.Прогноз движения: объект, орбитальные элементы на момент расчета, временной горизонт прогноза, дата расчета. Связана с сущностью «Космический объект» связью «один-ко-многим» (у одного и того же объекта движение может быть предсказано несколько раз, прогноз содержит предсказание только одного объекта).
5.Опасное сближение: время сближения, минимальное расстояние, вероятность столкновения, вовлеченные объекты, статус (обнаружено / уведомление отправлено / закрыто). Связана с сущностью «Уведомление владельцу спутника» связью «один-ко-многим» (один и тот же объект может быть в опасном сближении несколько раз)
6.Уведомление владельцу спутника: опасное сближение, владелец, рекомендации по маневру, дата отправки, реакция владельца (манёвр выполнен / отказ / не подтверждено), дата фиксации реакции. Связана с сущностью «Опасное сближение» связью «один-ко-многим» (один и тот же объект может быть в опасном сближении несколько раз)
7.Журнал обслуживания средств наблюдения: средство наблюдения, период простоя/обслуживания, причина, количество потерянных сеансов наблюдений. 
8.Владелец спутника: наименование организации, контактные данные, список эксплуатируемых спутников.

Процессы:
－регистрация объекта в каталоге — присвоение каталожного номера и идентификатора новому объекту;
－проведение наблюдения — сбор данных средством наблюдения;
－обработка результатов наблюдения — обновление орбитальных элементов, привязка к объекту;
－расчёт прогноза движения	— построение прогноза на основе актуальных элементов орбиты;
－присвоение статуса «утерян»	— автоматически, если срок отсутствия наблюдений превышен;
－повторное обнаружение —	сопоставление вновь обнаруженного объекта с утерянным, снятие статуса;
－расчёт опасных сближений	— анализ прогнозов на предмет пересечения траекторий;
－формирование уведомления	 — при превышении порога вероятности — генерация рекомендации владельцу;
－фиксация реакции владельца	— занесение в журнал ответа на уведомление; 
－плановое обслуживание средств	 — постановка на обслуживание, вывод из эксплуатации;
－регистрация отказа средства — фиксация выхода из строя, расчёт потерянных сеансов;
－составление расписания наблюдений —	планирование работы средств наблюдения; 
－формирование отчётности —	генерация отчётов по разным срезам.

Роли пользователей и права доступа:
－оператор наблюдения: вносит данные наблюдения, правит свои необработанные записи, просматривает свои данные, каталог;
－аналитик орбитального движения: создает прогнозы, расчеты сближений, обновляет орбитальные элементы объектов, просматривает весь каталог, наблюдения;
－специалист по уведомлениям: создает уведомления владельцам, редактирует статусы, уведомления, реакции владельцев, просматривает сближения, уведомления;
－инженер по обслуживанию средств: создает записи об обслуживании/отказах, обновляет статус средств наблюдения, просматривает журнал обслуживания средства;
－владелец спутника: подтверждает свою реакцию на уведомление, просматривает только свои уведомления и сближения;
－руководитель центра: создает расписания наблюдений, редактирует любые данные, может удалять данные, просматривает весь объем данных;
－администратор системы: создает учетные записи пользователей, обновляет права доступа, справочники, может удалять данные, просматривает весь объем данных.

Правила и ограничения:
－каждый наблюдаемый объект обязан иметь уникальный каталожный номер;
－каждый объект обязан иметь международный идентификатор;
－тип объекта строго ограничен множеством: действующий спутник, выведенный из эксплуатации аппарат, фрагмент, ступень ракеты;
－каждый объект обязан иметь размерную оценку;
－каждый объект обязан иметь текущие орбитальные элементы;
－объект может иметь статус «утерян». Статус «утерян» присваивается, если объект не наблюдался более установленного срока;
－снятие статуса «утерян» происходит только при повторном обнаружении объекта;
－повторно обнаруженный объект сохраняет свой прежний каталожный номер;
－тип средства наблюдения строго ограничен множеством: радиолокатор, оптический телескоп, лазерный дальномер;
－каждое средство наблюдения обязано характеризоваться зоной обзора, чувствительностью, режимом работы;
－при выходе средства наблюдения из строя фиксируется сокращение покрытия каталогизации;
－факт выхода из строя обязательно отражается в журнале с указанием потерянных сеансов наблюдений;
－по поступившим в центр наблюдениям выполняется обновление орбитальных элементов;
－по обновлённым элементам выполняется расчёт прогноза движения;
－обновление элементов и расчёт прогноза выполняются для каждого наблюдаемого объекта;
－опасные сближения рассчитываются только на основе прогнозов движения;
－опасные сближения рассчитываются между каталогизированными объектами и действующими спутниками;
－для каждого опасного сближения обязательно фиксируются время, минимальное расстояние, вероятность столкновения, вовлечённые объекты;
－уведомление владельцу спутника формируется только если вероятность столкновения превышает пороговое значение;
－уведомление обязательно содержит рекомендацию по маневрированию;
－реакция владельца строго ограничена множеством: выполнен маневр, отказ, не подтверждено;
－реакция владельца обязательно фиксируется в журнале;
－руководитель центра управляет расписанием наблюдений;
－руководитель центра координирует взаимодействие с владельцами спутников;
－руководитель центра формирует отчёты;
－руководитель центра не выполняет функции средства наблюдения (не производит наблюдения лично);
－руководитель центра не принимает решение о маневрировании за владельца спутника;
－отчёт обязательно содержит количество каталогизированных объектов по типам, количество опасных сближений за период, долю утерянных объектов, долю повторно обнаруженных объектов, охват орбитального пространства средствами наблюдения, среднее время между наблюдениями по объектам;
－отчёты формируются только руководителем центра;
－объект не может одновременно иметь статусы «наблюдаемый» и «утерянный»;
－опасное сближение не может существовать без вовлечённых объектов;
－уведомление не может быть сформировано без предшествующего расчёта опасного сближения;
－реакция владельца не может быть зафиксирована без сформированного уведомления;
－потерянный сеанс наблюдения не может быть зафиксирован без факта выхода средства из строя;
－повторное обнаружение не может быть зафиксировано для объекта, не имеющего статуса «утерян»;
－средство наблюдения не может наблюдать объект за пределами своей зоны обзора;
－средство наблюдения не может обнаружить объект ниже своей чувствительности;
－объект не может наблюдаться средством, режим работы которого несовместим с данным типом объекта.
－порог «утерян» определяется установленным сроком отсутствия наблюдений;
－обновление орбитальных элементов выполняется после поступления результатов наблюдений;
－расчёт прогноза выполняется после обновления орбитальных элементов;
－расчёт опасных сближений выполняется после расчёта прогноза движения;
－уведомление формируется после расчёта опасного сближения;
－реакция владельца фиксируется после формирования уведомления.

Отчетность:
Отчёт формируется только руководителем центра. Отчёт обязательно содержит все шесть разделов из п. 2. Отчёт формируется за период. Данные отчёта не могут противоречить журналу (журнал — первичен). Доли рассчитываются в процентах с указанием абсолютных значений.
При отсутствии данных по метрике указывается «нет данных» (не ноль). Отчёт не может включать объекты, не имеющие каталожного номера. Отчёт не может включать опасные сближения, не рассчитанные на основе прогнозов движения. Отчёт не может включать реакции владельцев без сформированного уведомления. Отчёт не может включать потерянные сеансы без факта выхода средства из строя.
