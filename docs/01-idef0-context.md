# 1. IDEF0: контекстная диаграмма (A0)

Mermaid не поддерживает IDEF0 нативно, поэтому блок A0 показан флоуграфом: **вход** — слева, **управление** — сверху, **механизм** — снизу, **выход** — справа.

```mermaid
flowchart LR
    IN1[/Данные о новых объектах/] --> A0
    IN2[/Реакция владельца спутника/] --> A0
    C1[/Правила и ограничения/] -.управление.-> A0
    C2[/Расписание наблюдений/] -.управление.-> A0
    C3[/Пороговые значения/] -.управление.-> A0
    M1[Руководитель центра] ==механизм==> A0
    M2[Средства наблюдения] ==механизм==> A0
    M3[Владельцы спутников] ==механизм==> A0
    A0["A0<br/>Управление каталогизацией и мониторингом космического мусора"]
    A0 --> O1[/Каталог объектов/]
    A0 --> O2[/Уведомления владельцам/]
    A0 --> O3[/Отчёты/]
    A0 --> O4[/Журналы/]
```
