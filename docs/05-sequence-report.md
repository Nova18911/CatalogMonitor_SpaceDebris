# 5. Процесс «Формирование отчёта руководителем центра»

## Mermaid

```mermaid
sequenceDiagram
    autonumber
    actor H as Руководитель центра
    participant S as Система
    participant C as Каталог объектов
    participant X as Модуль сближений
    participant J as Журнал
    participant T as Средства наблюдения

    H->>S: Запросить отчёт за период
    S->>C: Запросить объекты по типам
    C-->>S: Количество по типам
    S->>C: Запросить долю утерянных
    C-->>S: Доля утерянных (float)
    S->>J: Запросить повторные обнаружения
    J-->>S: Доля повторно обнаруженных (float)
    S->>X: Запросить сближения за период
    X-->>S: Количество сближений (int)
    S->>T: Запросить охват орбитального пространства
    T-->>S: Охват (float / %)
    S->>J: Запросить интервалы между наблюдениями
    J-->>S: Среднее время (float, часы)
    opt Данные отсутствуют
        S->>S: Указать «нет данных»
    end
    S-->>H: Отчёт (6 разделов)
```
