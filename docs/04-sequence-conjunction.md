# 4. Процесс «Расчёт опасного сближения и уведомление владельца»

## Mermaid

```mermaid
sequenceDiagram
    autonumber
    actor H as Руководитель центра
    participant S as Система
    participant C as Каталог объектов
    participant P as Модуль прогноза
    participant X as Модуль сближений
    participant J as Журнал
    actor O as Владелец спутника

    H->>S: Запустить расчёт сближений
    S->>C: Запросить прогнозы движения
    C-->>S: Список прогнозов
    S->>P: Рассчитать траектории
    P-->>S: Прогнозы движения
    S->>X: Рассчитать опасные сближения
    X->>X: Выбрать пары (каталогизированный + действующий)
    X->>X: Рассчитать время, расстояние, вероятность
    X-->>S: Список сближений
    alt Вероятность > порога
        S->>J: Зафиксировать сближение
        S->>S: Сформировать уведомление
        S->>J: Зафиксировать уведомление
        S->>O: Отправить уведомление с рекомендацией
        O-->>S: Реакция (манёвр / отказ / не подтверждено)
        S->>J: Зафиксировать реакцию
    else Вероятность <= порога
        S->>J: Зафиксировать сближение без уведомления
    end
```
